# AI Use Declaration - IPOS-PU

This project used AI assistance (Claude by Anthropic) in the following ways:

- **Initial project scaffolding** - generating the Spring Boot + JavaFX project structure, base entity classes, and repository/service/controller boilerplate
- **UI layout** - drafting FXML screen layouts and JavaFX controller wiring
- **Integration guidance** - advice on cross-subsystem REST API design between PU, SA, and CA
- **Debugging** - identifying Spring bean name conflicts (e.g. dual `CartController` classes) and JavaFX module issues
- **Code generation** - generating implementations of specific use cases (catalogue, cart, orders, payment, campaigns, admin) based on requirements from the Student Brief
- **Documentation** - drafting the development log, README, and integration docs

All generated code was reviewed, tested, and integrated by the team. The system design, use case mapping, and architectural decisions were made by the team with AI as an assistant.
